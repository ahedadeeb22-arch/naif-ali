# نظام إدارة مشتريات وتوزيع الخضروات وحسابات البقالات والموردين
> نظام إنتاجي ومحاسبي ورقابي متكامل (Production-Ready System) مبني بـ **Next.js 14+ (App Router)** و **TypeScript** و **Tailwind CSS** مع قاعدة بيانات علائقية متقدمة عبر **Supabase + PostgreSQL**.

---

## 🌟 نظرة عامة
تم بناء هذا النظام وفق النموذج المرجعي البصري والوظيفي (`gemini-code-1792530254546.html`) لتغطية الدورة اليومية الكاملة لتجارة وتوزيع الخضروات في سوق الجملة، مع تطبيق صارم لقواعد المحاسبة المالية المزدوجة وفصل الكميات الثلاث.

---

## 📱 الشاشات الخمس الأساسية ووضع المعاينة

1. **واجهة العامل (الكشف اليومي + جدول الطلبات المحفوظ):**
   - إدخال طلبات البقالات الليلية وحفظها في قاعدة البيانات.
   - كشف المشتريات الصباحي المباشر مع أزرار الكسور السريعة (`½`، `¼`، `1.5`، `1`، `2`).
   - إمكانية تكرار السطر `[+]` لشراء نفس الصنف من مورد ثانٍ بسعر ومورد مختلف.
   - مؤشر الفوارق اللحظي لكل سطر (فائض غير موزع / عجز / موزع بالكامل).
   - زر `[تم الشراء ✅]` وتلوين السطر، وعداد إنجاز الشراء الصباحي.
   - جدول طلبات البقالات المحفوظ للصباح (نقي بدون أسعار وموردين) وبطاقات فرز سيارات التوزيع.

2. **صفحة تقارير الأيام والتعديل الشامل (للمدير):**
   - أرشيف كروت أيام الأسبوع مع استعراض تقرير اليوم المنفرد وطباعة PDF.
   - وضع التعديل الشامل بالشريط البنفسجي وتثبيت التاريخ الأصلي للكشف.
   - حفظ التعديل وإعادة الترحيل المحاسبي الآمن بنفس التاريخ مع عكس القيود القديمة وحماية السندات النقدية.

3. **لوحة المدير (كشوفات البقالات والموردين):**
   - البطاقات الإحصائية الأربعة وحالة اليومية مع زر الإغلاق والاعتماد.
   - كشف حساب مورد مفصل (بالتاريخ) + زر `[💵 + تسجيل سند سداد للمورد]`.
   - كشف حساب بقالة مفصل (بالتاريخ) + زر `[💰 + تسجيل دفعة مستلمة من البقالة]`.
   - تقارير PDF العربية لكشوف الحسابات.

4. **لوحة المدير (الصلاحيات وسجل التدقيق):**
   - إدارة الكيانات (بقالات، موردين، أصناف، مستخدمين).
   - مفاتيح صلاحيات العامل الفورية (`Switches`) المحفوظة في قاعدة البيانات.
   - سجل التدقيق والمراجعة الشامل (`Audit Log`) يراقب كل حركة بالساعة والدقيقة والتفاصيل.

5. **بوابة صاحب البقالة (قراءة فقط):**
   - واجهة معزولة تماماً للمستأجر عبر سياسات `RLS`.
   - كشف حساب البقالة ومسحوباتها اليومية وسندات القبض المسددة.

6. **وضع المعاينة التجريبية المعزول (Demo Mode):**
   - متاح عبر الرابط `/demo` مع شريط تحذيري بارز وتفاعل حي كامل ببيانات العرض النموذجية دون المساس بالإنتاج.

## 🚀 تشغيل المشروع محلياً

```bash
# 1. تثبيت الحزم
npm install

# 2. إعداد متغيرات البيئة في .env.local (راجع .env.example)
# انسخ .env.example إلى .env.local وأضف بيانات مشروعك الخاص في Supabase:
# NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
# NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
# SUPABASE_SERVICE_ROLE_KEY=your-service-role-key

# 3. تشغيل خادم التطوير
npm run dev

# 4. بناء المشروع للإنتاج
npm run build
```
